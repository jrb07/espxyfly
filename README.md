## This project is a tabletop cartesian fluid dispensing robot with computer vision capabilities enabled by an ESP32-CAM

## The scripts include a main x_y_autofly_esp32.ino file which runs on the ESP32-WROOM with OLED which is the master MC

## There is another xyfly_cam.cpp which runs on the ESP32-CAM and will connect with and communicate to the master MC

## The master MC also acts as a WiFi configuration server and host for the index.html and config.html files

## The index.html is the main user interface and can redirect users to the config.html to configure the WiFi
