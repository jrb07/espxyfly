# This project is a tabletop cartesian fluid dispensing robot enabled by an ESP32

## The scripts include a main x_y_autofly_esp32.ino.cpp file which runs on the ESP32

## The ESP32 also acts as a WiFi configuration server and host for the index.html and config.html files

## The index.html is the main user interface and can redirect users to the config.html to configure the WiFi
